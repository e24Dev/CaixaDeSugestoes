# Checkpoint 03 — PostgreSQL, Flyway e JPA

Solução cumulativa até esta etapa. Requer JDK 17.

Requer PostgreSQL: `docker compose up -d --wait`. Os testes de integração requerem Docker.

Execute `./gradlew test` e `./gradlew bootRun` (Windows: `.\gradlew.bat`).
Servidor na porta 8000. Consulte o contrato em `docs/00-modelo-dados.md`.

Recursos posteriores estão nas respectivas branches `-impl`; a API completa
e as collections estão em `07-testes-entrega-impl`.
